# Anong Ganap? Capstone Abstract

Anong Ganap? is an AI-powered activity and experience planning platform designed to simplify how users organize dates, hangouts, family outings, and solo adventures. Traditional activity planning is often fragmented across multiple applications for map navigation, place discovery, budgeting, weather checking, messaging, and scheduling. This fragmented process can lead to decision fatigue, planning delays, and inconsistent user experiences. The proposed system addresses this problem by consolidating core planning tasks into a single intelligent workflow that generates complete, personalized, and actionable itineraries based on user preferences.

The project aims to develop a weather-aware planning system that accepts user inputs such as location, budget, activity type, available time, and transportation preference, then produces a structured itinerary with recommended destinations, route guidance, estimated costs, coordinated outfit suggestions, and invitation content. A key contribution of the system is contextual adaptation: the generated plan is not static but dynamically informed by real-time environmental data such as weather forecasts and route feasibility. For example, when weather conditions are unfavorable for outdoor activities, the system can recommend indoor alternatives while preserving the timeline and budget constraints.

From a technical perspective, the proposed solution follows a layered architecture. The presentation layer uses a React Native mobile interface as the primary user platform, with an optional React-based web admin/demo portal. The application layer is implemented using a Node.js and Express REST API responsible for orchestration, validation, and integration with external providers. The data layer uses PostgreSQL (Supabase) to store user profiles, plans, activities, outfits, invitations, and memory records. External integrations include AI services for itinerary and invitation generation, weather APIs for forecast retrieval, places and routing APIs for recommendation and navigation support, and email services for invitation delivery.

The development strategy is organized as an MVP-first implementation in phased iterations. The first phase establishes the mobile flow, backend skeleton, and database schema. The second phase implements core itinerary generation with places, route, and weather integration. The third phase adds differentiating features such as coordinated outfit recommendations, invitation generation, persistence, and quality validation through integration and end-to-end tests. Success metrics include plan completion rate, generation speed, invitation send rate, and repeat user engagement.

The expected outcome is a functional end-to-end planning assistant that reduces planning effort, improves itinerary quality, and enhances social experience preparation through automation and personalization. Beyond MVP, the project can be extended to include collaborative planning, preference learning, proactive weather alerts, offline support, and local booking integrations. As a capstone, Anong Ganap? demonstrates how applied AI, contextual data services, and practical software architecture can transform a common real-world pain point into an efficient, user-centered digital experience.

Keywords: artificial intelligence, itinerary planning, recommendation system, weather-aware personalization, mobile application, capstone project.
