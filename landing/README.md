# Anong Ganap? - Landing Page

Public-facing marketing website for Anong Ganap? AI-Powered Activity Planner.

## Purpose

This is the landing page that users will see when they visit the website. It showcases:
- Product features
- How it works
- Sample itinerary
- Call-to-action buttons

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

Visit http://localhost:5173

## Build

```bash
npm run build
```

Output will be in `dist/` folder, ready for deployment.

## Deployment

This can be deployed to:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting service
