# Shared Types and Constants

This folder contains TypeScript types and constants shared between frontend and backend.

## Usage

### In Backend (Node.js)
```javascript
// If using TypeScript
import { Plan, Activity } from '../shared/types.js';
```

### In Frontend (React/React Native)
```typescript
import { Plan, Activity, ActivityType } from '../shared/types';
```

## Files

- `types.ts` - Shared TypeScript interfaces and types
